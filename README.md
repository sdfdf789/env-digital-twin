# 全国生态环境数字孪生监测平台

以中国三维地图为核心的环境监测数据可视化大屏，蓝色科幻风格，全部数据来自公开可核验的权威接口，并完整处理加载、降级与异常状态。

## 一、快速运行

**方式 A：直接双击 `index.html`**
地图边界走内置兜底文件（`data/china-geo.js`），实时数据走 HTTPS 接口，双击即可看到完整效果。

**方式 B：本地静态服务（推荐，行为与线上一致）**

```bash
node server.js          # 打开 http://127.0.0.1:8300
# 或
python -m http.server 8300
```

> 首次打开需联网拉取实时数据；断网时会自动进入「推演」模式，界面依然完整可用。

## 二、技术选型与素材来源

| 类别 | 选型 | 获取方式 | 选型理由 |
|---|---|---|---|
| 三维渲染 | **Three.js r128**（603 KB，非模块版） | `cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js` → 本地 `vendor/` | 唯一成熟的 WebGL 通用库；r128 为全局 `THREE` 版本，无需构建工具，单文件即可交付 |
| 图表 | **Apache ECharts 5.5.0**（1.0 MB） | `cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js` → 本地 `vendor/` | 仪表盘/雷达/玫瑰图/折线开箱即用，中文排版与工业大屏生态最匹配 |
| 行政区边界 | **阿里云 DataV.GeoAtlas** `100000_full.json`（569 KB） | `geo.datav.aliyun.com/areas_v3/bound/100000_full.json` → 本地 `data/` | 基于自然资源部标准地图服务，含 **台湾、香港、澳门、南海诸岛（九段线）** 要素，34 个省级面要素可直接拉伸成三维 |
| 空气质量数据 | **Open-Meteo Air Quality API**（底层 ECMWF **CAMS** 大气成分场） | `air-quality-api.open-meteo.com/v1/air-quality` | 免注册、免 Key、支持多坐标批量查询与 CORS，含 PM2.5/PM10/O₃/NO₂/SO₂/CO 六参数与 24h 逐小时历史 |
| 气象数据 | **Open-Meteo Weather API**（ECMWF IFS） | `api.open-meteo.com/v1/forecast` | 用于「静稳天气」研判与播报，同样免 Key |
| 视觉素材 | 纯代码生成，无位图素材 | — | 光晕/网格/粒子/渐变全部由 Canvas 纹理 + Shader 混合模式实时生成，无版权风险、无外链图片、可无限缩放不糊 |

**为什么不用地图瓦片服务（高德/腾讯/天地图）**：本页是"数据驱动 + 自绘三维行政区"的数字孪生表达，需要按省级数值实时改变几何高度与颜色，瓦片底图无法承载；同时避免引入任何地图 Key，交付即用、无鉴权泄漏风险。

**为什么 AQI 由平台自己折算**：Open-Meteo 只给出污染物浓度与欧洲/US AQI，国内公众口径是《环境空气质量指数(AQI)技术规定》**HJ 633-2012**。平台取六项分指数 IAQI 的最大值作为 AQI、最大项作为首要污染物，与官方口径一致（换算逻辑见 `js/config.js` 中 `iaqi()`）。

## 三、数据来源、更新频率与降级策略

| 板块 | 来源 | 源更新频率 | 平台拉取频率 | 失败处理 |
|---|---|---|---|---|
| AQI 与六项污染物 | Open-Meteo / CAMS | 逐小时 | **10 分钟** | 首次失败即切本地推演 + 顶部红条 + 面板「推演 DATA」水印；指数退避 10s→20s→…→300s 重试，成功后自动恢复实时 |
| 24h 污染物趋势 | Open-Meteo（`hourly` + `past_days=1`） | 逐小时 | 10 分钟（全国均值）；单省下钻按需拉取并缓存 6 分钟 | 缺失小时置空不断线；全缺失显示占位空态 |
| 气象协同 | Open-Meteo / IFS | 逐小时 | **15 分钟** | 仅置灰相关字段，不影响主视图 |
| 地表水水质类别 | 生态环境部《中国生态环境状况公报》口径 / 国家地表水自动监测数据发布平台 | 年度·季度 | 页面加载读取，每日 08:00 校验版本 | 标注「基线」，缺失时读内置常量 |
| 污染源排放构成 | 全国排污许可证管理信息平台公开端（行业聚合） | 季度 | 页面加载读取 | 标注「基线」 |
| 省级三维边界 | DataV.GeoAtlas | 静态 | 构建期下载本地化，运行期零请求（file:// 用内置兜底） | 底数缺失时提示错误，绝不渲染错误边界 |

页面内点击右上角 **数据库图标** 可随时查看这张表（含每项接口地址与口径说明）。

**数据性质标注**：每个面板右上角都有标签 —— <kbd>实时</kbd> 来自公开 API 实际拉取、<kbd>基线</kbd> 为权威公报口径的内置数据集、<kbd>推演</kbd> 为接口不可用时的本地降级数据。**不会把推演数据伪装成实时数据。**

## 四、界面结构

```
┌──────────────────────── 顶部栏：标题 / 视图切换 / 接口状态 / 倒计时 / 时钟 ───────────────────────┐
├─ 左栏（4 面板） ─┬────────────── 三维中国地图 ─────────────┬─ 右栏（4 面板） ─┤
│ AQI 环形仪表      │ 图层切换（空气 / 水质 / 污染源）        │ 24h 污染物趋势   │
│ 六项污染物雷达    │ 省份悬停卡片 + 点击下钻                 │ 污染源构成玫瑰图 │
│ 省会 AQI 排名     │ 南海诸岛插图（合规）                    │ 实时预警流       │
│ 地表水水质类别    │ 图例 / 视角工具 / 比例说明              │ 数据源健康度     │
├──────────────────┴── KPI 五联指标（含迷你趋势） ──────────┴──────────────────┤
└──────────────────────── 实时滚动播报条 ─────────────────────────────────────┘
```

**交互**：拖拽旋转、滚轮/双指缩放、悬停高亮并显示监测卡片、点击省份下钻（左栏雷达、省份卡片、右栏趋势同步切换为该省会真实序列）、图层三选一、排名正反排序、立即刷新、全屏、`ESC` 关闭弹窗。

**响应式**：`≥1400` 三栏大屏；`1240–1400` 收窄三栏；`<1240` 单列上下堆叠（地图置顶、面板两列）；`<860` 手机单列，隐藏图例/工具栏、缩小插图与省份卡片，页面可滚动。断点实测无横向溢出。

## 六、合规说明与已知边界

- 地图数据基于自然资源部标准地图服务衍生数据（DataV.GeoAtlas，**审图号 GS(2019)1719 号**），页面底部常驻标注「仅作示意，不作为行政界线依据」；台湾、香港、澳门按省级行政区正常着色统计；南海诸岛以右下角插图 + 九段线表达，符合标准地图表示习惯。
- 未接入任何境外地图服务、未内嵌任何地图 API Key、不涉及涉密或受限地理信息。
- 本页为数据可视化演示：水质、污染源为公报口径基线而非实时断面数据（国控断面接口需鉴权代理，接入后可平滑替换 `data-service.js` 中的 `loadBaseline()`）。
- 省会监测点取省政府驻地坐标，代表城市尺度而非全省面平均。
- 所有时间按 `Asia/Shanghai` 对齐，数据时次以接口返回的 `current.time` 为准，显示在 AQI 面板「统计时次」。

| 构建 | 无构建步骤，推送 `main` 后由 GitHub 自动发布，约 30–90 秒生效 |

**更新流程**（改完代码后）：

```bash
git add -A
git commit -m "描述本次改动"
git push origin main      # 推送后自动重新发布
```

**首次从零部署**：运行 `bash deploy-github.sh`（幂等脚本，完成建仓 → 推送 → 开启 Pages → 轮询上线）。脚本依赖已登录的 Git Credential Manager 凭据，不含任何硬编码令牌。

**注意**：GitHub Pages 在中国大陆访问速度不稳定，首次加载需下载 1 MB 的 ECharts 与 600 KB 的 Three.js，弱网下首屏可能等待 10–30 秒（页面已有引导加载层与进度提示）。如需国内加速，可将本仓库镜像到 Gitee Pages 或任意对象存储 + CDN，静态资源路径全部为相对路径，无需改代码。
